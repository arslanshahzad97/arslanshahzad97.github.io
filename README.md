# Arslan Shahzad — Senior Full Stack Developer

A world-class, premium SaaS-style personal portfolio built with modern web technologies. Designed with a luxury bright palette, immersive Three.js hero animations, and fluid GSAP scroll interactions.

## ✨ Features

- **Immersive 3D Hero** — Floating geometric compositions rendered with Three.js and `RoomEnvironment` for realistic PBR lighting
- **Premium Bright Aesthetic** — Warm whites, champagne gold accents, and editorial typography (Playfair Display + Inter)
- **Fluid Scroll Animations** — GSAP ScrollTrigger powers staggered reveals, parallax effects, and counter animations
- **Bento-Grid Skills** — Modern asymmetric layout showcasing e-commerce, CMS, and DevOps expertise
- **Interactive Timeline** — Career history with elegant scroll-triggered entrances
- **Fully Responsive** — Optimized for desktop, tablet, and mobile devices
- **Zero Build Step** — Runs natively in the browser via CDN; perfect for GitHub Pages

## 🛠 Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, grid, flexbox, glassmorphism, and responsive design
- **JavaScript (ES6+ Modules)** — Modular, performant vanilla JS
- **Three.js** — 3D hero scene with mouse-reactive parallax
- **GSAP + ScrollTrigger** — Production-grade animations and scroll interactions
